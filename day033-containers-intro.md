# Day 33 – Introduction to Containers
## VM vs Container
| VM                  | Container           |
| ------------------- | ------------------- |
| Heavy               | Lightweight         |
| Has full OS         | Shares host OS      |
| Slow startup        | Starts in seconds   |
| More resource usage | Less resource usage |
## Key terms
- Image       - Read-only blueprint (like a class)
- Container   - Running instance of an image (like an object)
- Dockerfile  - Text file with steps to build an image
- Registry    - Image storage (Docker Hub, ECR, GCR)
## Why DevOps uses containers
- Same environment everywhere
- Faster deployments
- Easy CI/CD integration
- Scales well with Kubernetes
