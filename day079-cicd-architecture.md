# Day 079 – CI/CD Pipeline Architecture

## 🎯 Objective

Understand end-to-end CI/CD pipeline for Kubernetes deployments.

---

## 🧠 CI/CD Flow

Git push
↓
Build Docker image
↓
Push to container registry
↓
Deploy to Kubernetes
↓
Rolling update
↓
Health checks

---

## 🧠 Pipeline Stages

1. Source
2. Build
3. Test
4. Push
5. Deploy

---

## 🧠 Tools

CI: GitHub Actions  
Registry: Docker Hub  
CD: Kubernetes deployment  

---

## 🧠 Key Takeaway

CI/CD automates build, push, and deployment to Kubernetes.
